# SE prototype reference

`customer_review_prototype.html` is the Solution Engineering vision prototype for the future
Customer Review screen (received 2026-08). It is a standalone static HTML mock with hard-coded
illustrative data. Open it directly in a browser; it is deliberately **not** part of the deployed
demo (`scripts/build-site.mjs` does not copy `docs/`).

`alignment-plan.md` compares the prototype with the current demo and lists the alignment work,
including where the prototype's language must be reframed to respect this repository's claims
boundaries (AI drafts and explains only; deterministic systems validate, compare, qualify,
calculate, and execute; authorized people and the CIS workflow retain approval and customer-state
authority).
